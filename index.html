01

Hệ Thống Quản Lý Sinh Viên

Ứng dụng web fullstack quản lý toàn diện thông tin sinh viên, lớp học và điểm số theo học kỳ. Hỗ trợ phân quyền người dùng, tìm kiếm nhanh và xuất báo cáo thống kê.

  Vai trò: Fullstack Developer
  • Quản lý CRUD sinh viên, lớp học, môn học
  • Phân quyền Admin / Giáo viên / Sinh viên
  • Tìm kiếm, lọc và sắp xếp dữ liệu nâng cao
  • Xuất báo cáo điểm số theo từng học kỳ
💡 Bài học: Nắm vững RESTful API, xác thực người dùng và thiết kế cơ sở dữ liệu quan hệ trong môi trường thực tế.
NodeJS Java HTML/CSS MySQL

Website Quản Lý Phòng Trọ

  Vai trò: Backend Dev & UI Designer
  • Quản lý danh sách phòng và trạng thái sử dụng

NodeJS Java HTML/CSS MySQL
03

Ứng Dụng Quản Lý Công Việc

Ứng dụng To-do cá nhân cho phép người dùng tạo, phân loại và theo dõi tiến độ công việc theo ngày. Hỗ trợ lưu trữ local, lọc theo trạng thái và giao diện dark/light mode.

  Vai trò: Frontend Developer
  • Thêm, sửa, xóa và đánh dấu hoàn thành công việc
  • Lọc công việc: tất cả / đang làm / đã xong
  • Lưu dữ liệu bền vững với LocalStorage
  • Dark mode tự động và responsive toàn thiết bị
